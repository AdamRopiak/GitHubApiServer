
# GitHubApi RestController




## Description

Simple REST server to mediates the download data from GitHub API server about user and his repo
## Getting Started


### Dependencies

 - WebFlux
 - Lombok
 
### Installation

Download zip file, extract to your enviornment and just run in IDE. Server is waiting for requests. 
Default server: http://localhost:8080
### Program execution

Use your favirite tool to send GET request.
In your request use endpoint /githubapi/{gitHubUserName}
